# Instagram diagnostic patch
Replace the matching paths in GitHub and commit. Run Actions > Daily Marine Forecast PNG > Run workflow.

The generator logs the actual peak wind, peak wave, low tide and source timestamp present at image creation. It rejects literal Unavailable placeholders. Empty fields remain hidden by the Instagram HTML.

The workflow serves instagram/index.html, not root index.html. If the logs show the correct peaks but the viewed image is still wrong, check the workflow commit and generated today.png. No private GAS code included.
