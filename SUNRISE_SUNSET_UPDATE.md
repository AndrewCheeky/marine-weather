# Sunrise and sunset v5

- Adds sunrise and sunset in Jamaica local time to the Instagram poster, just below the date.
- Calculated from Maiden Cay latitude/longitude using approximate NOAA solar geometry, with no external API calls.
- Preserves moon, tide, weather and bank data.
- Install integrated Apps Script (replace existing, deploy New version) and replace instagram/index.html in GitHub.
- Keep existing GitHub Actions and generator files unchanged.
- Solar event times are approximate, not official astronomical almanac values.
